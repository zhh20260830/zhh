情绪卡

普拉切克情绪模型 · 8 种基础情绪，心理学常用

核心认知

没有坏情绪，只有情绪传递的信号；
情绪本身不是问题，压抑、回避才是问题。

四组对立的原始情绪
喜悦 ↔ 悲伤
愤怒 ↔ 恐惧
信任 ↔ 厌恶
期待 ↔ 惊讶
复合情绪 · 两两混合
愤怒 + 期待 = 急躁
喜悦 + 信任 = 爱
悲伤 + 恐惧 = 绝望
愤怒 + 厌恶 = 鄙视
关于情绪的三句话
  • 情绪从不矛盾：可以同时开心又难过、愤怒又害怕，多重情绪共存是身心正常状态。
  • 表层情绪藏深层需求：愤怒多源于受伤，焦虑多源于失控，悲伤多源于在乎。
  • 觉察优先级：先看见情绪、接纳情绪，再分析问题、调整状态，不急于对抗、消除情绪。

记录时不用对号入座。
知道情绪有名字、可以被拆解，就已经在拉开距离了。

情绪觉察

复合情绪拆解 · 看见情绪背后的心理

底层逻辑

  • 复合情绪 = 2 种及以上基础情绪 + 认知想法（经历、信念、评判）
快乐 悲伤 愤怒 恐惧 惊讶 厌恶
复合情绪对照
焦虑
恐惧+期待

对还没发生的事，害怕坏结果，心里悬着。例：担心失败、担心长胖、压力悬而未决。

急躁 · 烦躁
愤怒+期待

事情达不到预期，等待、受阻，内心焦灼。

怀念
快乐+悲伤

回忆过去美好的事，一边回味，一边感慨已经逝去。

委屈暴食高频
悲伤+愤怒

自己觉得被不公平对待，心里受伤又生气，却无法直接发作。夜间暴食非常高频触发的情绪。

羞耻暴食高频
厌恶（指向自己）+悲伤

觉得自己很差、丢人，自我否定，向内攻击。暴食之后大量出现：“我怎么又控制不住”。

内疚 · 愧疚
悲伤+愤怒（向内）

认为自己做错事，内心自责。区别羞耻：内疚是对行为不满；羞耻是对“我这个人”的否定。

嫉妒
愤怒+恐惧+悲伤

看见别人拥有，自己渴望却得不到；害怕自己落后，夹杂失落。

羡慕
快乐+悲伤

欣赏别人的美好，同时夹杂自己求而不得的失落。

绝望
恐惧+悲伤

看不到希望，觉得处境无法改变，无力感很强。

空虚暴食高频
悲伤+缺少期待

没有具体害怕、生气的对象；心里空洞，没有满足感。夜间暴食最常见的情绪——身体不累，但内心空洞，想用食物填补。

失望
悲伤+惊讶

事情的结果远低于自己内心期待。

尴尬
惊讶+厌恶+恐惧

当众出糗，害怕被别人负面看待。

怨恨
愤怒+悲伤

过去受到伤害，一直放不下，反复回想受伤经历。

感激
快乐+信任

得到善待，内心温暖，产生回馈的想法。

应对技巧
  1. 识别预警信号：焦虑、空虚、强烈想要吃禁忌食物，情绪波动。
  2. 10–15 分钟延迟技术：离开当前环境，喝水、散步，延迟冲动。冲动峰值一般 10–15 分钟，不会一直持续上涨。
  3. 区分饥饿还是情绪：生理饥饿是缓慢到来；贪食的渴望突然爆发，只想特定高热量食物，大多是情绪驱动。
暴饮暴食原因

食物充当情绪缓冲

  • 压力逃避：通过不停进食来逃避要花费时间和心力去做的事
  • 沮丧进食：大脑空白，对前途的迷茫，即缺少一个清晰特定的奋斗目标。
暴饮暴食坏处
  • 糟践自己的生命
  • 伤害自己的健康
  • 浪费来之不易的粮食
  • 恶性循环，只是逃避上瘾
